# committee-response

## Inputs and scope

Committee comments, draft/proposal, decisions, evidence and institutional format.

Use the user's requested language and deliverable format. This Skill supplies a workflow; it does not install services or grant access to accounts. Resolve tool availability in the current host before relying on an external backend.

## Workflow

1. Group comments by issue while preserving attribution and original meaning.

2. Draft responses stating action, rationale and precise location, or evidence-based disagreement.

3. Separate completed edits from proposed experiments and decisions requiring the author's input.

4. Check consistency across response letter and revised material.

## Deliverable and verification

Committee response, issue/change matrix and remaining commitments.

Do not fabricate approvals, meetings or institutional requirements; do not send the response without authorization.

Report what was actually inspected, executed and rendered. Preserve existing user work and authorization boundaries for external messages, publishing, paid compute and destructive cleanup.
