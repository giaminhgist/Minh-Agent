# ethics-and-preregistration

## Inputs and scope

Study design, data/participant context, hypotheses, analysis plan and applicable institutional requirements.

Use the user's requested language and deliverable format. This Skill supplies a workflow; it does not install services or grant access to accounts. Resolve tool availability in the current host before relying on an external backend.

## Workflow

1. Identify data provenance, consent/privacy concerns, participant risks and required oversight from the actual study.

2. Separate confirmatory hypotheses and analyses from exploratory work; specify outcomes, exclusions and stopping rules before results are examined.

3. Draft preregistration and ethics materials with unresolved institutional inputs clearly marked.

4. Check consistency with the experiment plan and record amendments with dates and reasons.

## Deliverable and verification

Ethics considerations, preregistration draft, analysis commitments and missing approvals.

Drafting does not confer ethics approval or establish legal compliance; never backdate preregistration.

Report what was actually inspected, executed and rendered. Preserve existing user work and authorization boundaries for external messages, publishing, paid compute and destructive cleanup.

Prepare a preregistration draft that distinguishes primary outcomes from exploratory analyses.
