# integrity-forensics

## Inputs and scope

Artifacts, allegation or audit scope, raw evidence access and available forensic backend.

Use the user's requested language and deliverable format. This Skill supplies a workflow; it does not install services or grant access to accounts. Resolve tool availability in the current host before relying on an external backend.

## Workflow

1. Inventory evidence and record what is unavailable before choosing checks.

2. Perform deterministic consistency checks on claims, tables, logs and code. Preserve an obligations ledger and source anchors for each finding.

3. For a full Anti-Autoresearch sweep, require a verified compatible external installation and its execution contract; this bundle does not embed that engine.

4. Report the achieved scope and unresolved obligations; distinguish suspicious inconsistency from a supported misconduct conclusion.

## Deliverable and verification

Evidence inventory, findings, obligations and explicit triage/full-sweep status.

Codex deterministic-only triage cannot yield CLEAN or full-sweep parity. Unsupported external execution remains UNSUPPORTED.

Report what was actually inspected, executed and rendered. Preserve existing user work and authorization boundaries for external messages, publishing, paid compute and destructive cleanup.

## Mode details and sources

Read [source contracts](references/source-contracts.md) when selecting an upstream mode, provider adapter or checking feature parity. Those notes distinguish implemented guidance from upstream functionality still requiring tools or verification.

## Example

Check conflicting reported metrics while clearly separating triage from a full forensic sweep.
