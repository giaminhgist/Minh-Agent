# literature-review

## Inputs and scope

Research question, domain, date range, inclusion scope and accessible sources.

Use the user's requested language and deliverable format. This Skill supplies a workflow; it does not install services or grant access to accounts. Resolve tool availability in the current host before relying on an external backend.

## Workflow

1. Choose quick overview, full survey, annotated bibliography, novelty comparison or WHY/HOW/WHAT comparison. Record search queries, dates and databases used.

2. Use available provider tools for their actual strengths: arXiv versions/PDF, OpenAlex metadata/graphs, Exa similarity, Firecrawl full-page extraction, or Gemini/other discovery. Verify discovered papers against accessible primary sources.

3. Separate abstract-only evidence from full-text reading. Deduplicate versions, group methods and compare the closest work against the proposed contribution.

4. For communication/networking tasks inspect the local knowledge base first and apply domain/venue constraints. Return unresolved gaps and a reproducible search trail.

## Deliverable and verification

Source ledger, synthesis, comparison matrix and bounded novelty conclusion.

Unavailable providers get a declared fallback, not a claimed equivalent search. Use systematic-review for protocol-based exhaustive review.

Report what was actually inspected, executed and rendered. Preserve existing user work and authorization boundaries for external messages, publishing, paid compute and destructive cleanup.

## Example

Find the nearest prior work to a proposed low-memory inference method.
