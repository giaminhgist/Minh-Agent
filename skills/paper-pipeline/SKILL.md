# paper-pipeline

## Inputs and scope

Paper objective, available evidence, source format, venue constraints and entry stage.

Use the user's requested language and deliverable format. This Skill supplies a workflow; it does not install services or grant access to accounts. Resolve tool availability in the current host before relying on an external backend.

## Workflow

1. Inspect existing artifacts to enter at the appropriate stage rather than redrafting everything.

2. Connect evidence audit, narrative plan, drafting, citation verification and figure production with explicit handoff artifacts.

3. Run revision and build steps, preserving unresolved claims and missing experiments in an audit ledger.

4. Before final delivery check completeness of sources, bibliography, figures and rendered pages. Label stages not executed and avoid submission without authorization.

## Deliverable and verification

Editable paper package, PDF when compiled, provenance and stage-by-stage audit coverage.

A drafted manuscript is not a completed pipeline if required figures, citations or build remain unresolved.

Report what was actually inspected, executed and rendered. Preserve existing user work and authorization boundaries for external messages, publishing, paid compute and destructive cleanup.
