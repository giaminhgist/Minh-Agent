# patent-claims

## Inputs and scope

Invention disclosure, supported embodiments, terminology and jurisdiction context.

Use the user's requested language and deliverable format. This Skill supplies a workflow; it does not install services or grant access to accounts. Resolve tool availability in the current host before relying on an external backend.

## Workflow

1. Identify the technical feature set and draft a coherent independent claim candidate.

2. Add dependent claims that narrow meaningful variants with consistent antecedent basis.

3. Build a feature-to-description support map and check for unexplained terms or unsupported breadth.

4. Present alternatives and rationale for professional review.

## Deliverable and verification

Claim set, dependency tree, support map and drafting issues.

Do not promise enforceability or filing readiness; unsupported features stay flagged.

Report what was actually inspected, executed and rendered. Preserve existing user work and authorization boundaries for external messages, publishing, paid compute and destructive cleanup.
