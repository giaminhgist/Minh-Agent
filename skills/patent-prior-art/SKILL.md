# patent-prior-art

## Inputs and scope

Technical disclosure, relevant dates, terminology, jurisdictions and search scope.

Use the user's requested language and deliverable format. This Skill supplies a workflow; it does not install services or grant access to accounts. Resolve tool availability in the current host before relying on an external backend.

## Workflow

1. Extract mechanisms, components, synonyms and classification candidates from the disclosure.

2. Search available patent databases and literature; retain query/date/coverage records and distinguish priority, filing and publication dates.

3. Map candidate disclosures to specific invention features with source passages and drawings.

4. Separate relevance screening from conclusions requiring professional legal analysis.

## Deliverable and verification

Prior-art ledger, feature comparison, dates and search limitations.

A search cannot establish absence of prior art or legal patentability; inaccessible databases limit coverage.

Report what was actually inspected, executed and rendered. Preserve existing user work and authorization boundaries for external messages, publishing, paid compute and destructive cleanup.
