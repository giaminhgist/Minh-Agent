# patent-workflow

## Inputs and scope

Disclosure, desired stages, jurisdiction and available evidence.

Use the user's requested language and deliverable format. This Skill supplies a workflow; it does not install services or grant access to accounts. Resolve tool availability in the current host before relying on an external backend.

## Workflow

1. Establish scope and existing artifacts; enter at the appropriate stage.

2. Carry feature identifiers and source evidence across prior-art, invention, claims and specification tasks.

3. Run support and consistency reviews before formatting; preserve unresolved questions for professional review.

4. Deliver a versioned package and a stage ledger, without automatically filing or contacting third parties.

## Deliverable and verification

Patent drafting package, provenance, review findings and handoff.

A complete workflow artifact set is not a legal clearance or patentability guarantee.

Report what was actually inspected, executed and rendered. Preserve existing user work and authorization boundaries for external messages, publishing, paid compute and destructive cleanup.
