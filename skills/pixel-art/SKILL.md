# pixel-art

## Inputs and scope

Subject, palette, dimensions, animation states and transparency requirements.

Use the user's requested language and deliverable format. This Skill supplies a workflow; it does not install services or grant access to accounts. Resolve tool availability in the current host before relying on an external backend.

## Workflow

1. Choose a native pixel resolution and silhouette before adding shading.

2. Use an available image or pixel-editing tool; maintain consistent pixel scale, palette and light direction.

3. For animation keep canvas, anchors and frame timing consistent; inspect at native and enlarged nearest-neighbor scale.

4. Export the requested asset and document dimensions/palette.

## Deliverable and verification

Pixel-art image or spritesheet, palette and animation metadata when applicable.

No image tool means a production brief rather than a finished asset; do not blur-resize pixel artwork.

Report what was actually inspected, executed and rendered. Preserve existing user work and authorization boundaries for external messages, publishing, paid compute and destructive cleanup.

Create a small transparent pixel icon with a limited palette.
