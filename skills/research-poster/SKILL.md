# research-poster

## Inputs and scope

Paper, physical dimensions, venue requirements, figures and author details.

Use the user's requested language and deliverable format. This Skill supplies a workflow; it does not install services or grant access to accounts. Resolve tool availability in the current host before relying on an external backend.

## Workflow

1. Plan the reading path and allocate physical space to the central claim and evidence.

2. Build HTML/CSS with explicit print dimensions and real high-quality assets; retain editable text and source.

3. Render at the intended size and measure overflow, clipping, image resolution and section density. Export PDF using an actual print renderer.

4. Validate author details, citations, QR targets and figure provenance. Treat the legacy paper-poster name as an alias to this HTML workflow.

## Deliverable and verification

HTML/CSS/assets, rendered preview, print PDF when available and layout checks.

Do not resurrect retired LaTeX poster behavior or claim print readiness without a rendered size check.

Report what was actually inspected, executed and rendered. Preserve existing user work and authorization boundaries for external messages, publishing, paid compute and destructive cleanup.

## Mode details and sources

Read [source contracts](references/source-contracts.md) when selecting an upstream mode, provider adapter or checking feature parity. Those notes distinguish implemented guidance from upstream functionality still requiring tools or verification.

## Example

Create an A0 landscape poster using supplied paper figures.
