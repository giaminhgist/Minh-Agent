# scientific-illustration

## Inputs and scope

Concept, reference images, scientific relationships, labels, publication style and output size.

Use the user's requested language and deliverable format. This Skill supplies a workflow; it does not install services or grant access to accounts. Resolve tool availability in the current host before relying on an external backend.

## Workflow

1. Separate conceptual illustration from data plots and precise diagrams. Use native image-generation/editing capability when available and required by the host.

2. Prepare a composition brief specifying scientific objects and relationships; keep labels limited and verify them after generation.

3. Generate or edit with the chosen renderer, inspect geometry, arrows, text and misleading scientific implications, and revise within scope.

4. Retain prompt/reference provenance and export actual image artifacts; use a vector overlay when precision is required.

## Deliverable and verification

Illustration, generation provenance, revisions and verified caption.

Unavailable image generation yields a design brief, not a claimed rendered figure. Do not manufacture experimental evidence.

Report what was actually inspected, executed and rendered. Preserve existing user work and authorization boundaries for external messages, publishing, paid compute and destructive cleanup.
