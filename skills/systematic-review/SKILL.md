# systematic-review

## Inputs and scope

Review question, protocol, databases, eligibility, extraction fields and synthesis plan.

Use the user's requested language and deliverable format. This Skill supplies a workflow; it does not install services or grant access to accounts. Resolve tool availability in the current host before relying on an external backend.

## Workflow

1. Define question, search strategy, eligibility and planned synthesis before selection; document amendments.

2. Run reproducible searches and deduplicate with retained record identities. Perform screening with transparent stage decisions.

3. Extract data, assess methodological limitations and choose an appropriate synthesis; only pool studies when designs and measures justify it.

4. Reconcile included/excluded counts and state search coverage, bias and unresolved records.

## Deliverable and verification

Protocol, search/screen/extraction ledgers, synthesis and review limitations.

A broad narrative survey is not a systematic review. Do not infer missing study data or pool incompatible outcomes.

Report what was actually inspected, executed and rendered. Preserve existing user work and authorization boundaries for external messages, publishing, paid compute and destructive cleanup.
